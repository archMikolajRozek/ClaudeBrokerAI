# AI Portfolio Manager - UI Dashboard

## Overview
React/Next.js dashboard dla AI Portfolio Manager.

## Features
- Real-time portfolio monitoring
- Trading signals visualization
- Market data charts
- Risk metrics dashboard
- Alert notifications

## Tech Stack
- React 18
- Next.js 14
- TailwindCSS
- Chart.js / Recharts
- WebSocket (dla real-time updates)

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
